# Shree Raja Ram Bangles (Bangle Maison)

A luxury e-commerce storefront and executive admin portal for **Shree Raja Ram Bangles**.

## 🌟 Features
- **Responsive Hero Carousel**: 2:1 ratio full-width responsive slider with touch swipe support.
- **Shop by Collection**: 8 curated bangle categories (*Traditional*, *Bridal*, *Kundan*, *Meenakari*, *Pearl*, *Glass*, *Kids*, *Gold Plated*).
- **Catalog & Filter Bar**: Instant category filtering, price sorting, and quick product modals.
- **Executive Admin Portal** (`/admin`): Real-time inventory tracking, orders management, categories, and customer records.
- **Brand System**: Royal maroon & champagne gold luxury palette with responsive typography.
